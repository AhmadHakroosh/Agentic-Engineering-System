# Examples

Examples demonstrate how to drive the delivery agents; they are not application templates or pre-approved production designs.

- [Task API](task-api/README.md): builds a small Python HTTP API from a manual ticket snapshot and takes it through requirements, architecture, implementation, independent review, and a pull request.

To adapt an example, change the ticket's objective, acceptance criteria, and constraints. Keep the staged prompts: analyze first, approve explicitly, implement second, and review the final commit independently.
